# 板材設計　広島バージョン　１．０

中学校技術科の木工作品設計を支援する、ブラウザで動くDIYサポートアプリです。

## 🔗 アプリを開く

**https://igarikatsuya-glitch.github.io/itazai-hiroshima/**

## 概要

HTMLファイル1個だけで動作します。インターネット接続不要・インストール不要で、ブラウザで開くだけで使えます。

### 主な機能

- **Step1 材料を切り分ける** — のこぎり・糸のこ盤・ベルトサンダー・自在ぎりに対応した切断シミュレーション
- **Step2 部品を配置する** — 切り出した部品を3D空間に配置して組み立て構想図を作成
- **材料取り図・構想図の印刷・PDF出力**
- **設計データのJSON保存・読み込み**（授業をまたいで作業継続可能）

### 広島バージョンでの追加機能

元の板材設計アプリに以下の機能を追加しています。

- **教員設定** — 木種名・板材の枚数・各板のサイズ（幅・高さ・板厚）を学校ごとにカスタマイズ可能。設定はブラウザに保存されます。
- **表示倍率（ズーム）** — Step1の材料図を ー / ＋ / 全体 ボタンで拡大・縮小。大きな板材を設定した場合もスクロールなしで全体が確認できます。
- **PDFで保存** — Step3（設計の保存・構想図）からPDFとして印刷・保存できます。

## 使い方

上のURLをブラウザで開くだけで使えます。オフラインで使う場合はアプリ内の「外部通信・ライセンス」→「端末にダウンロード」からHTMLファイルを保存してください。
